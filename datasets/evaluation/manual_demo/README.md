# Manual evaluation demo

This tiny dataset was authored specifically to test dataset loading and
evaluation plumbing. The query-document relevance grades were assigned
manually by the project author (2 = directly relevant, 1 = partially relevant,
0 = not relevant; omitted pairs are treated as grade 0). The original content
is dedicated to CC0-1.0. It is not a representative benchmark and its results
must not be presented as evidence of general retrieval quality.

See `manifest.json` for version, provenance, citation and license link. The
files use the local JSONL/BEIR qrels layout and require no download.
